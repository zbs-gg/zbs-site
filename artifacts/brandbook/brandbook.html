07

Rules

If the page is only grey labels and one ASCII gif — rewrite it.

Do

  • white (or holo) type on solid dark plates
  • ≥4 live effect stages when teaching motion
  • people + context scenes for product story
  • icons / mood stills on every component card
  • cyan = signal only · holo = data edges
  • GSAP / canvas / SVG — authored motion with light + thickness
  • section indices as thin outline watermarks, not rainbow digits

Don't

  • 5% frosted glass that disappears on black
  • particle networks / matrix rain / blockchain 2015
  • flat “3D” that only bends with no edge or light
  • holo rainbow section numbers as decoration
  • tiny uppercase eyebrows · ALL CAPS micro titles
  • slop copy: “seamlessly”, “elevate”, “unlock”
